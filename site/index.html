The problem

Finding a product is only half the job.

A confident answer isn't a verified purchase.

The wrong variant, an unsupported feature, an untrusted merchant, or unknown shipping can change the decision. An AI-generated checkout request should never become spending authority on its own.

DIAPORIA separates research, verification, preparation, and human authorization—so each step has a reason and an accountable result.

How it works

From request to verified decision.

Same MCP session, one continuous purchasing workflow.

01 / RESEARCH

Understand the exact request.

Extract the model, variant, budget, MUST requirements, and preferences. Unresolved requirements stay open.

02 / EVIDENCE

Verify before recommending.

Manufacturer-backed facts are attributable. Unverified features don't silently become facts.

03 / OFFERS

Compare the real total.

Merchant checks and fresh quotes distinguish listing prices from verified item, shipping, and tax totals.

04 / AUTHORITY

Keep spending with the human.

The AI prepares checkout. Server-enforced limits and the human approval flow decide whether it may proceed.

Try it yourself

Run the demo. No keys needed.

Node.js 22.13+ required. The dependency installation needs access to npm; the actual demo uses no paid APIs.

git clone https://github.com/friendly-neighborhood-coding-man/diaporia-agent-commerce.git
cd diaporia-agent-commerce
git checkout feature/buy-browser-panel
npm ci
npm run demo:full

The offline demo runs 18 checked steps using fictional products, merchants and MOCK payments. No PayPal API call, no real funds.
